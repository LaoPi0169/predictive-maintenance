# 试点计划（Pilot Plan）— 影子运行

- 项目：设备预测性维护 AI Agent（MVP 已交付，见 `docs/test-report.md`）
- 日期：2026-10-27 · 状态：待设备/维修团队确认后启动
- 原则（spec §十一/§十二）：先影子运行（只读验证），确认稳定后再授权写入；
  **维护 Agent 不是安全仪表系统**，不替代设备自身保护逻辑，绝不直接控制
  PLC 或绕过安全联锁。

## 1. 目标与范围

- **范围**：一台离心泵（对应演示资产 P-103 的真实同型设备）、一个故障模式
  （轴承退化：振动/轴承温度/电机电流趋势）；
- **目标**：在影子运行期验证——① 预警提前量与误报率在真实数据上可复现
  合成基线水平；② Agent 诊断与知识引用被现场工程师判定"可用"；③ 工单
  草稿字段满足 CMMS 录入要求；
- **方式**：**影子运行（shadow mode）**——系统只读消费数据并产出评估/
  建议/工单草稿，**不提交任何工单、不下任何采购**；人工对照现有流程。

## 2. 数据与接入要求

| 项 | 要求 | 决策点 |
|---|---|---|
| 历史 | ≥ 2 周 1-min 级 CSV（振动/轴承温度/电流/压力/负载/运行状态） | 与 historian 导出格式对齐 |
| 实时 | OPC UA / MQTT / Historian 轮询其一；断线补传与时钟同步说明 | 厂内 IT 确认网络分区与只读账号 |
| 质量标记 | 传感器质量位/停机段说明 | 设备工程师提供 |
| 基线 | 近 6–12 个月非计划停机记录、MTBF/MTTR 现值 | 用于 §10.3 对照（无基线不评估收益） |
| 故障标签 | 期间内真实故障/检修事件清单 | 事后标注，供召回率核对 |

## 3. 运行程序（周粒度，建议 4–6 周）

1. **W1 接入与校准**：历史数据过 M1 质量门 → 设备工程师确认 EXAMPLE_RULE
   （报警限值、可操作风险级别 `AGENT_ACTIONABLE_RISK_LEVELS`、审批角色）→
   基线指标在真实数据上重算（`model_evaluation` 同款回放）；
2. **W2–W3 影子运行**：每日自动评估 → 看板呈现 → 工程师在"工单审核"页
   以人工决定代替自动提交（系统仅留痕）→ 每次高风险事件记录：
   是否提前预警、提前量、是否误报、Agent 建议是否采纳及理由；
3. **W4 对照与重校准**：召回率/误报率/提前量按 §10.2 重校准（按故障事件
   划分，单独统计每种故障模式，稀疏故障报告样本量与置信区间）；知识库
   补充现场 SOP/案例后重跑 RAG 评测（阈值需重新校准）；
4. **W5 验收评审**：对照本计划 §5 成功标准 → 决定进入授权写入（真实
   CMMS 对接）或延长影子期/终止。

## 4. 角色与职责

| 角色 | 职责 |
|---|---|
| 设备工程师（试点负责人） | 阈值确认、每日判定、第五层验收清单（`docs/test-report.md` §五） |
| 维修技师 | 工单草稿可执行性反馈 |
| 数据/IT | 数据接入、网络分区、只读账号 |
| 项目/FDE | 系统运行、指标统计、报告 |

## 5. 成功标准（进入授权写入的门槛，EXAMPLE_RULE 需确认）

- 预警提前量 ≥ 维修准备时间（初值参考 48 h，由维修准备流程确定）；
- 已知/复盘故障事件召回率 ≥ 85%（按事件与故障模式统计）；
- 误报率不超过约定上限（初值：每周 ≤ 1 次 HIGH 级误报）；
- Agent 建议采纳率与"有依据率"由工程师判定达标；工单字段零返工；
- 无未授权提交、无重复工单（系统保证，试点期复核）；
- 无安全联锁/控制行为（架构性保证，持续复核）。

## 6. 退出与回滚标准

- 连续 2 周误报超上限且重校准无效 → 暂停预警推送，仅保留数据质量层；
- 数据质量持续不达标（隔离率异常）→ 修复采集后再入影子期；
- 任何安全相关异常 → 立即停止系统对维护流程的介入（数据采集可保留）；
- 影子运行不影响现有维护流程：随时可退回纯人工流程（系统只读，无回滚成本）。

## 7. 已知限制与生产化前提（spec §十一）

- 演示级身份头 → 试点需接入真实认证（最小权限、凭证管理）；
- 模拟 CMMS 引用 → 试点对接真实 EAM/CMMS（先只读、后授权写入）；
- 规则+统计引擎（`rules-stat-v1`）非训练模型：有监督模型（方案 B）与 RUL
  （方案 C）待真实故障标签积累后评估；
- 评测集/知识库为合成语料 → 试点期须以真实手册/SOP 重建并重跑全部门禁；
- 跨进程 LangGraph checkpoint、容器化部署、监控告警 → 试点通过后按
  §十一生产化清单实施。
